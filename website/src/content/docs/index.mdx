## What is Bearcat?

Bearcat runs on your desktop, NAS, or server. You manage your releases in a web interface,
and Bearcat creates archives, uploads them to your hosters, checks the links, and reuploads
files that go offline.

You can:

- Pack releases into RAR or 7z archives, or upload archives you already have.
- Upload to Rapidgator, DDownload, Keep2Share, and the other hosters listed below.
- Free local disk space and [restore archives from a mirror hoster](/Bearcat/mirror-downloads/) when a reupload needs them.
- Look up release information and NFOs through xREL and SRRDB, movie or TV metadata through TMDB and TheTVDB and game metadata through Steam.
- Read resolution, codecs, and audio and subtitle tracks from your video files with MediaInfo.
- Upload cover images and use them alongside download links and NFOs in [BBCode templates](/Bearcat/forum-post-templates/).
- [Prepare forum drafts](/Bearcat/posting-to-forums/) for review or [post automatically](/Bearcat/automatic-forum-posting/) using rules you configure.
- Track releases you still need to post with the [post queue](/Bearcat/post-queue/).

## Common questions

### Can I upload existing archives?

Yes. Bearcat can upload archives you created yourself. These are called unmanaged releases.
For managed releases, Bearcat creates the archives from your release files.
See [release types](/Bearcat/release-types/) for how the two work.

### Do I have to keep every archive on disk?

No. If you enable a hoster as a mirror, Bearcat can download the archives again when a reupload
needs them. You can delete local copies yourself or set a retention period for automatic cleanup.

The hoster must support downloads through its API, and some hosters require a premium account.
See [mirror downloads](/Bearcat/mirror-downloads/) for supported hosters and setup instructions.

## Supported services

### File hosters

- Rapidgator
- DDownload
- GoFile
- [Keep2Share](/Bearcat/keep2share/)
- Alfafile
- NitroFlare
- 1fichier
- Uploady.io
- Katfile
- Krakenfiles
- FileQ
- UploadG.com
- FileServe.com
- Clicknupload.click
- HxFile.co
- file-upload.org
- datavaults.co (maximum file size: 100 MB)
- Fast2Share.com
- CloudFam.io
- freedl.ink (minimum file size: 1 MB)
- mega4upload.net
- turbobit.net (API key from cabinet.costaction.com)
- hitfile.net (API key from cabinet.costaction.com)

### Linkcrypters

- Hide.cx
- Keeplinks
- tolink.to
- [filecrypt.cc](/Bearcat/filecrypt/)

### Image hosters

- ImgBB
- pixhost.to (no API key needed)
- pixelfox.cc
- loepic.me
- directupload.eu (no API key needed)

### Forums

Basic XenForo support is available for data-load.me and boerse.cx.
