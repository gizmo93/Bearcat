# Bearcat Docs Website

This is the Astro + Starlight documentation site for Bearcat user documentation.
It uses the Starlight Nova theme.

## Commands

Run commands from this `website` directory:

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the local docs server |
| `npm run build` | Build the production site to `dist/` |
| `npm run preview` | Preview the production build locally |

The source pages live in `src/content/docs/`. Screenshots used by the pages live next to the Markdown files in `src/content/docs/images/`.
